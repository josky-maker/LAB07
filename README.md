# LAB07 SPI 사전 검증 자료

2026-11-02 실험 준비: Mode 0, 8비트, MSB 우선 SPI 송수신.

| 사진 | 내용 |
|---|---|
| 01 | FPGA SPI 수신 전체 파형 |
| 02 | FPGA 0x55 수신 확대 파형 |
| 03 | FPGA SPI 송신 전체 파형 |
| 04 | FPGA 0xA5 송신 확대 파형 |
| 05 | STM32 마스터 코드와 빌드 화면 |
| 06 | STM32 슬레이브 빌드 화면 |

PNG 6개는 제공된 Word 파일 내부 원본을 그대로 추출했습니다. manifest.json에 SHA-256을 기록했습니다.
LAB07_sources.zip에는 관련 HDL, 테스트벤치, XDC, STM32 C 변형 파일이 있습니다. STM32 전체 기반 프로젝트는 수업 ece2_474 프로젝트가 필요합니다.

사진은 사전 시뮬레이션과 빌드 근거입니다. 보드 측정 결과가 아닙니다. 송신 테스트벤치는 100 MHz 및 HALF_CYCLES=5로 시간을 줄였으므로 50 MHz 보드용 파형과 구분해야 합니다.
보고서는 별도로 제출합니다.
