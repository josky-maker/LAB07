# LAB07 SPI 실험 자료

2026-11-02 과제 8~12 사진 12장과 영상 4개입니다. 보고서는 별도 제출합니다.

- task8: MCU 송신 파형과 로그
- task9: MCU 간 송수신
- task10: MCU에서 FPGA로 송신
- task11: FPGA에서 MCU로 송신과 수신 로그
- task12: FPGA 두 대의 연결 시연

사진은 원본, _preview.mp4는 웹 열람용 변환본입니다. 원본 전체는 postlab-v1.0.0 릴리스의 LAB07_postlab_originals.zip에 보관합니다. manifest.json에 원본 이름, 크기, SHA-256을 기록했습니다.

LAB07_postlab_sources.zip은 2026-11-02 로컬 소스 보관본입니다. 기본 MOSI E8 및 대안 G8 제약을 포함합니다. 실제 다운로드 bitstream과 동일한지는 확인되지 않았습니다. STM32 변형 C 파일은 수업 기반 프로젝트가 필요합니다.

자료에 없는 UART 로그나 별도 계측값은 성공 근거로 삼지 않습니다.
